VOICE BOOTH

Keep the voices you’ll miss hearing.

A private voice and photo guestbook for weddings, birthdays, anniversaries, and the gatherings worth remembering.

Made for meaningful events

Turn an iPhone or iPad into a shared wedding audio guestbook. Every voice message can include up to six optional photos, and memories stay on the devices chosen by the host.

Private by design

  • Secure Host sign-in
  • Guests need no account or public media library
  • No advertising or tracking
  • Monthly Host subscription; guests stay free

Guests can leave a voice message and up to six optional photos at the shared Booth. A Host may also enable a short-lived, protected Web Guest QR session; the host imports and saves each message locally. The host can replay, organize, export, and relive event memories in a full-screen Memory Show.

Bring every voice home

Create a local 16:9, 1080p Memory Movie from an Event. Voice messages play from oldest to newest with each guest’s own photos; messages without photos use the Event theme. The original recordings stay unchanged, and the movie leaves the app only when the Host chooses a destination in the iOS share sheet.

Host-controlled guest access

Web Guest access is short-lived and can be revoked when the Event ends. Private temporary media is deleted after the Host imports and acknowledges it, after revocation, or when its secure holding period expires.
